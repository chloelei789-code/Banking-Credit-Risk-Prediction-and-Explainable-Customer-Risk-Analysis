# Banking-Credit-Risk-Prediction-and-Explainable-Customer-Risk-Analysis
Business Problem
Credit risk assessment is an important task for financial institutions. The objective of this project is to investigate whether customer demographic, credit, repayment, and payment behavior can be used to predict the probability of default in the following month.

Target
default = 1
non-default = 0

Research Questions
RQ1：Which customer characteristics are associated with credit default?
RQ2：Which repayment and payment behaviors are most strongly related to default risk?
RQ3：Can machine learning models accurately identify customers with higher default risk?
RQ4：Which features contribute most to the model's predictions?
